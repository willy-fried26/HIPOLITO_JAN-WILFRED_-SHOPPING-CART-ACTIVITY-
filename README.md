# HIPOLITO_JAN-WILFRED_-SHOPPING-CART-ACTIVITY-
This is my take on quiz 2 and 3 on computer programming 2 where I created a simple shopping cart system

Features
Shows a list of products with price and stock
Lets the user choose items and enter quantity
Checks if the input is valid
Prevents buying more than the available stock
Updates the cart instead of adding duplicate items
Displays the total and applies a 10% discount if it reaches ₱5000
Shows the updated stock after checkout

How It Works

The program displays the menu, then asks the user to select a product and quantity. It checks if the input is correct and if there is enough stock before adding it to the cart. The user can keep adding items until they stop, then the program shows the receipt and total.
